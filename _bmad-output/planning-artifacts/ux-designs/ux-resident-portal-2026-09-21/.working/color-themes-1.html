Resident Portal — Color Theme Explorations

Five palette directions for the same UI moment: a landlord's tenant list, with rent in ₹ and a payment status that must never be ambiguous ("pending" vs "completed" are distinguished by color, border weight, icon, and text — not color alone). Each theme is shown as a light/dark pair. Semantic token names are identical across themes; only the hex values change.
